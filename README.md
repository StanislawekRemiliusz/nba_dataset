
## 📊 Player Performance Analysis

This project includes detailed player-level analytics:

- top scorers and playmakers
- player efficiency metrics
- starter vs bench comparison
- impact of turnovers
- plus/minus analysis

## 🔗 Combined Analysis

- team performance vs individual performance
- correlation between player stats and team success

## Technology
- SQL(PostgreSQL/MySQL)
- python

## How to use
1. lunch shema.sql
2. add data by load_data.py
3. lunch queries.sql
